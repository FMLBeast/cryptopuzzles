# ARweave Cryptopuzzle Collection

This repository contains a comprehensive collection of ARweave cryptographic puzzles, their solutions, and methodologies. The data is structured for AI model training and cryptographic research.

## Overview

In 2019, an Arweaver known as 'Tiamat' created a series of complex cryptographic puzzles with substantial AR token rewards. These puzzles employ various cryptographic techniques including steganography, ciphers, logic puzzles, and blockchain concepts.

## Project Structure

```
/puzzles/
  /solved/          - Detailed information on solved puzzles
  /unsolved/        - Information on active unsolved puzzles
  /techniques/      - Documentation of cryptographic techniques used
/data/
  puzzle_index.json - Complete puzzle catalog
  statistics.json   - Analytics and statistics
```

## Puzzle Statistics

- **Total Puzzles Created**: 13+ identified

- **Total Unclaimed Rewards**: 1000+ AR tokens (~$21,000+ USD)

## Notable Puzzle Types

1. **Mathematical Logic Puzzles** - Algebraic problems, probability calculations
2. **Historical Knowledge Puzzles** - Identifying figures from historical clues
3. **Steganography Challenges** - Hidden information in images
4. **Cipher Puzzles** - Various encoding schemes (A1Z26, Morse, Bacon)
5. **Blockchain-specific Puzzles** - SHA-256/SHA-384 references, wallet mechanics
6. **Visual Pattern Recognition** - Image analysis and reverse image search
7. **Chess Puzzles** - FEN notation and chess moves
8. **Cryptarithm Puzzles** - Alphanumeric substitution problems
